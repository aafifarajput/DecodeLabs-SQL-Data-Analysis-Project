# DecodeLabs – SQL Data Analysis Project

## Project Overview
This project was completed as part of the DecodeLabs Data Analytics Internship. The objective was to analyze e-commerce order data using SQL and extract meaningful insights through data querying and aggregation.

## Tools & Technologies
- PostgreSQL
- pgAdmin 4
- SQL

## Dataset
The project uses a cleaned e-commerce orders dataset containing 1,200 records and 11 columns, including:
- Order ID
- Order Date
- Product
- Quantity
- Unit Price
- Payment Method
- Order Status
- Items in Cart
- Coupon Code
- Referral Source
- Total Price

## SQL Concepts Applied
- SELECT and WHERE
- ORDER BY
- GROUP BY
- COUNT(), SUM(), AVG()
- HAVING
- Percentage calculations
- Date-based analysis
- Data validation and quality checks

## Analysis Performed
- Analyzed order distributions across products.
- Examined order statuses and payment methods.
- Evaluated referral sources and coupon usage.
- Explored monthly and yearly order trends.
- Calculated aggregate order metrics.
- Performed basic data quality checks.

## Key Findings
- The dataset contains 1,200 orders.
- The most frequently ordered product was Printer.
- Cancelled and Returned orders represented approximately 41.4% of all orders.
- The dataset covers January 2023 to June 2025.

**Note:** Total order value represents recorded order value across all order statuses, not confirmed revenue.
